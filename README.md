# Welcome to Chromer

Chromer is a version of Chrome set up for this project. Here’s how to get
started:

## Open Chromer

1. In VS Code, open the **Ports** panel.
2. Select port **3000** to open the Chrome browser.
3. Select port **43083** to visit the Chromer homepage.

On the homepage, select the **Toby** shortcut to open Toby in Chrome in a new
tab. Toby may not be available on every network.

## Send feedback

Select port **43084** to open the feedback form. You can use it to suggest an
app or tell us about a problem. Please don’t include passwords or other
private information.

If you need to contact me, tell me what happened and how you opened Chromer.
That information can help me understand the problem.

## If something isn’t working

Try rebuilding the container in VS Code:

1. Select the blue bar at the bottom of the VS Code window.
2. Search for **Rebuild Container** and select it.

If it still doesn’t work, use the feedback form to let me know.

## Search tip

When searching, type **Hi** first, then type the web address you want.
